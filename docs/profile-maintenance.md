# Profile artwork and synchronization

The README's Selected Projects section follows the public repository pins on [JasonTM17's GitHub profile](https://github.com/JasonTM17). Change the profile pins to change the selection; there is no separate curated project list to maintain. Pin order, descriptions, and primary language come from GitHub GraphQL `user.pinnedItems`. Public repositories contributed to under another owner are supported. Private pins are never rendered.

Recently Updated shows up to five other public projects, excluding the pinned URLs before selecting the entries. The full collapsed Browse All catalogue still includes every public project once. If every eligible public project is pinned, the empty recent subsection is omitted. This avoids repeated project summaries while keeping the complete catalogue available.

The [sync workflow](../.github/workflows/sync-public-projects.yml) requests the current pins and public repository archive every five minutes, offset from the hour. GitHub can delay scheduled jobs; this is polling, not an instantaneous event stream. To refresh on demand, open **Actions → Sync pinned projects and portfolio → Run workflow**. The workflow must exist on the default branch before its schedule is active.

The workflow uses its existing `GITHUB_TOKEN` with `contents: write` to read public metadata and commit changed README/card assets. It creates no commit when the snapshot is unchanged, apart from the existing 45-day schedule keepalive. HTTP failures, GraphQL errors (including partial data), and invalid metadata leave the previous showcase untouched. A valid empty pin list clears the selection. Slot-based generated filenames remove old cards when a repository is unpinned.

## Terminal banner

The banner is local artwork generated by [build-terminal-banner.py](../scripts/build-terminal-banner.py). It has desktop/mobile and light/dark GIFs. The identity, headline, and focus areas remain visible throughout the 8.26-second loop; only the last command and cursor change. Static SVG variants are selected when `prefers-reduced-motion: reduce` is active.

Rebuild with Python 3 and Pillow (`python -m pip install Pillow` in your chosen environment):

```sh
python scripts/build-terminal-banner.py
```

The generator discovers Segoe UI/Consolas on Windows or DejaVu fonts on Linux. Explicit `--regular-font`, `--bold-font`, and `--mono-font` arguments are available. Different installed fonts can change rasterized pixels; cross-platform pixel parity is not claimed. The committed assets require no runtime or external image service.

## Chat design preview

The chat preview lives in the ordinary project folder `work/readme-preview/`. On this installation, the default visualization directory is a Windows junction; the installed reader rejects link ancestors, and its resolved storage location is outside this project's permitted roots. Keeping the fragment in the workspace fixes the read boundary without changing the installed app, security checks, or signed skill bundle. A real variant-selection event from that workspace path confirmed chat loading.

Local generation and tests do not mean the profile has been published. A commit/push and a successful workflow run must be observed separately before claiming live synchronization.

## Contribution animation

The existing contribution workflow uses pinned Platane snk v3.5.0 to retrieve the real GitHub calendar. `scripts/style-contribution-snake.mjs` preserves its contribution cells and initial levels, then builds a varied route using shuffled choices of nearby unvisited cells. A seed derived from the calendar makes generation repeatable and keeps light/dark motion identical. Changes to the calendar can produce a different route. This is a precomputed SVG loop; it does not choose a new random path in the browser on every repetition.

Routing tracks the entire four-cell snake and allows only states that can return to the exact starting pose. All four segments stay inside the matrix, follow one shared route with one-cell delays and restart continuously. Each grid step takes 160ms, so a longer route does not make the snake race. Cell clearing follows the head's first visit. The head fits a calendar cell; both eyes share its animation. There is no outside shadow or clipping mask hiding excursions.

The compact rounded surface, quieter grid spacing and mint palette have light/dark variants. The unlabelled collection indicator is hidden. Static SVGs keep the initial calendar visible and hide moving elements for reduced motion.

The four SVGs are regenerated on the existing daily schedule, on relevant default-branch pushes, or with **Actions → Update contribution animation → Run workflow**. They are published to the existing `output` branch. Contribution snapshots are separate from the five-minute pinned-project sync and are not real-time activity counters.

Local styling checks: `node --test scripts/style-contribution-snake.test.mjs`. After generating fresh upstream files, run `node scripts/style-contribution-snake.mjs dist` before publication. The formatter intentionally rejects unsupported or already-styled SVG inputs.
