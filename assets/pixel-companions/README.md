# Pixel coding companions

A compact decorative strip requested for the personal README: a mint coding robot and an orange Claude/Clawd-inspired companion. The supplied artwork is fan art; it does not indicate affiliation.

- `source-sheet.png`: original transparent 4 × 2 sprite sheet, copied from the built-in imagegen result without painting or retouching.
- `coding-duo.gif`: eight encoded frames, 360 × 210, 6.1-second loop; displayed at 300px in the README.
- `coding-duo.png`: static transparent first frame for reduced motion.

Generated with the **built-in imagegen tool**, then extracted/aligned/scaled/encoded by `python scripts/build-pixel-companions.py` (Pillow). The renderer preserves the source sheet and PNG alpha, uses a reserved transparent GIF palette entry, and adds no service or network dependency.

## Initial robot prompt

```text
Create an original, production-quality pixel-art animation sprite sheet for a small decorative strip beneath a professional software developer's GitHub README cover. ONE sheet, 4 columns by 2 rows, exactly 8 equal-size cells, landscape canvas 1536x1024, true transparent background, no grid lines, no captions, no text, no watermark. In every cell repeat the SAME tiny adorable ivory-and-mint robot at the SAME scale and SAME fixed position, sitting at a low minimal desk with a dark laptop, a tiny succulent on the right. Front three-quarter view. Robot has a compact cuboid head, two friendly dark square eyes, tiny mint antenna, short little arms, tasteful navy pixel outlines. Restrained ivory, mint green, dark teal and muted gray palette matching a sober dark terminal-style developer profile. Crisp authentic pixel art, all edges on a consistent square pixel grid, no blur, gradients, lighting glow, painterly texture or 3D rendering. Each scene must be fully isolated inside its cell, same baseline, same desk and laptop positions and identical outer silhouette bounds; plenty of transparent padding. Reading order left to right then second row: frame 1 robot typing, eyes open; frame 2 same, tiny alternating hand typing motion; frame 3 same with eyes gently closed for a blink; frame 4 back to typing with eyes open; frame 5 robot raises right hand in a small friendly wave, laptop and desk fixed; frame 6 hand wave tilted slightly, eyes smiling; frame 7 right hand lowers back to typing; frame 8 identical to frame 1 to close the loop. Keep variations very small; no body bouncing or composition changes. No human, no words, no giant scenery. The finished animation should feel calm, sweet, and polished rather than visually busy.
```

## Final two-character edit prompt

```text
Edit this sprite sheet to add a SECOND character in EVERY frame: the recognizable Claude Code / Clawd orange pixel mascot that the user likes — a very simple wide terracotta-orange block body, two black square eyes, four little blocky legs and small side protrusions, no nose, no humanoid arms, no ears, no robot antenna on the orange character. The existing ivory-and-mint coding robot at its laptop and tiny plant remain the other character. Composition: each equal cell now contains the small robot working at a compact desk on the left and the small orange Clawd companion on the floor on the right, sharing a stable baseline. Both clearly visible, cute and tasteful. Keep the navy outlines, ivory, mint and muted orange palette; make pixel blocks flat and crisp. Remove ALL ambient glow, gradients, fog, shadows outside the silhouettes and semi-transparent halos: true transparent background around the sharp sprites. Output ONE landscape sprite sheet, 4 columns x 2 rows, exactly eight equal cells, preferably 2048x1024 pixels, no lines or labels. Precisely identical placement, scale and stationary furniture in all cells, scene centered inside each cell with generous transparent margins. All eight cells contain the same TWO characters, furniture and plant; no extras. Read left to right, top to bottom: 1 robot typing and orange mascot eyes open; 2 tiny alternating typing hands, orange legs change in place by one pixel; 3 robot blink and orange eyes open; 4 both neutral; 5 robot small right-hand wave, orange blink; 6 robot wave with smiling eyes, orange has a tiny raised front leg; 7 both return to neutral; 8 same as 1 for a seamless calm loop. No whole-scene camera motion or bobbing. All cells aligned. No text, letters, numbers, brand wordmarks or watermark. This is decorative fan art for a personal GitHub profile, not an endorsement banner.
```
